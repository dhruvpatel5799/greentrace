# GreenTrace

AI-powered climate accountability platform - AI Builder Cup 2026 (Hack2Skill x Google Cloud).

## Modules
1. Supply Chain Carbon Auditor
2. Green Bond Verifier

## Structure
- /api - Node.js/Express backend
- /earth-engine-service - Python microservice for Earth Engine
- /web - React/Next.js frontend
- /scripts - one-off data loading scripts

## Setup
See root .env for config. Never commit greentrace-backend-key.json or .env.
